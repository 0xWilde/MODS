# MODS

Tools and fixes for games I mod. Each game gets its own folder.

| Game | Tool | What it does |
|---|---|---|
| Skater XL | [XLGM Cleaner](Skater%20XL/XLGMCleaner/) | finds duplicate and unused XLGearModifier gear and moves it out of the way, with undo |

Ready-to-run downloads (with Python bundled, nothing to install) are on the [Releases](../../releases) page.
